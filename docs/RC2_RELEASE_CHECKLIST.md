## 復帰音

以下を各3回以上行う。

1. ゲーム画面でBGM再生中にiPhoneをスリープし、10秒後に解除。
2. 解除後、画面へ触れず2秒待つ。
3. 余白を一度タップ。
4. 選択肢を一度タップ。

期待:

- 解除だけでは無音
- 余白tapで謎のSEなし
- BGMは自然にfade-in
- 選択肢SEは1回だけ

追加:

- ホーム画面へ戻ってから再開
- アプリスイッチャー経由で再開
- BGM mute、SE mute、両方mute
- 機内モード中の再開

## ダブルタップ

次の場所をダブルタップする。

- タイトル背景
- タイトルカード余白
- ゲーム本文
- 選択肢外の余白
- 記録カード
- 設定項目
- モーダル内余白

期待:

- ダブルタップ拡大なし
- 縦スクロール可能
- ピンチズーム可能
- スライダー操作可能
- テキスト入力可能
