# v4.9.0 rareバランス検証と固定seedログ

`TabenaiSurvival.simulatePolicies` と `TabenaiSurvival.playSeed` を使用し、実ゲームと同じイベント抽選、効果、日次処理、終端判定、保存PRNGで検証した。方針選択だけはゲーム保存PRNGと独立した決定論的PRNGを使う。true rareは `rare` カテゴリだけを数え、`conditional`、`milestone`、`final` は含めない。

## 実装定数

| 日 | true rare基礎率 |
| --- | ---: |
| 1〜19 | 0.8% |
| 20〜34 | 1.0% |
| 35〜44 | 1.2% |
| 45〜49 | 1.5% |

- `rareSeen === 0` かつ未遭遇31抽選以上のランだけ、35日目から1日ごとに0.2ポイントを加算する。
- 実効率は最大4%。soft pityは発生を保証しない。
- 最初のtrue rare後はsoft pityを解除する。
- 2回発生後はtrue rare抽選を停止し、条件付き・節目・最終イベントは継続する。
