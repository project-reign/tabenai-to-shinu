# 食べないと死ぬ：50日目の晩餐

二つの選択肢だけで50日目の「最後の晩餐」を目指す、ブラウザ向け怪食サバイバル・ノベルです。v4.3.0 はiPhone縦画面とPWA運用を強化し、v4.2.1の既存セーブをそのまま引き継ぎます。

## 遊ぶ

GitHub Pagesで公開する場合のURLは次の形式です。

```text
https://project-reign.github.io/tabenai-to-shinu/
```

初回だけオンラインで起動すると、ゲーム本体とアイコンが端末へ保存されます。以後は同じURLまたはホーム画面のアイコンからオフラインでも再起動できます。

管理操作はヘッダー右端の `☰` にあります。

- インストール・更新
- 遊び方
- シードの確認
- 共有
- セーブ移行
- 手動保存
- 最初から

新版が待機中になると画面下部へ通知が表示されます。「更新する」を選ぶまで現在の版を維持するため、プレイ中の不意な再読み込みはありません。進行は更新前に既存localStorageキーへ自動保存されます。

## ゲーム上の保証

- 各画面の選択肢は常に二つ
- 食べない、飲まない、何もしないという拒否を選択可能
- 白い土、赤い土、灰色の土、身体発芽の黒豆ルートを維持
- 最後の晩餐は四皿を二段階の二択で選択
- 同一シードと同一選択列で乱数結果を再現
- v2、v3、v4.2.1のlocalStorageセーブを現行スキーマへ正規化

保存スキーマは v4.2.1 と同じ `version: 4`、保存キーは `tabenai-to-shinu-50days-v4` のままです。アプリの表示バージョン `4.3.0` と保存スキーマを分離しているため、更新によって既存の進行を失いません。

## ローカル開発

Node.js 24 以上を使用します。

```bash
npm ci
npx playwright install chromium
npm run serve
```

テストサーバーはGitHub Pagesと同じサブパスを再現します。

```text
http://127.0.0.1:4173/tabenai-to-shinu/
```

## テスト

```bash
npm test
```

Playwrightテストは次を自動検証します。

- 44シーンの全102選択遷移と条件付き遷移
- 全拒否選択
- 常時二択
- 白・赤・灰色の土と身体発芽
- 最後の晩餐の四皿と最後の拒否
- 同一シードの再現性
- v2、v3、v4.2.1セーブ移行
- iPhone縦画面の初期到達距離
- GitHub Pagesサブパス上のmanifestとService Worker
- 初回オンライン起動後のオフライン再起動
- 新版の待機と明示更新

公開用ファイルは次で `dist/` に作成します。

```bash
npm run build
```

## GitHub Pages

`.github/workflows/pages.yml` はPull Requestでテストとビルドを実行し、`main` へのpushでテスト成功後に `dist/` をGitHub Pagesへ配信します。リポジトリの Pages Source は **GitHub Actions** を選択してください。
